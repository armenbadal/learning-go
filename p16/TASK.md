# Խնդիր 2․ Task Manager ծառայություն

Միջին

Նպատակ՝ սովորել gRPC-ն կիրառել իրական backend ծառայություն կառուցելիս։

Գրիր առաջադրանքների կառավարման ծառայություն։

### Տվյալների մոդել

Յուրաքանչյուր առաջադրանք ունի՝

- `id` — եզակի նույնացուցիչ,
- `title` — վերնագիր,
- `description` — նկարագրություն,
- `completed` — ավարտված լինելու նշան։

### Պահանջվող մեթոդներ

| Մեթոդ          | Նպատակ                          |
| -------------- | ------------------------------- |
| `CreateTask`   | Ստեղծել առաջադրանք              |
| `GetTask`      | Ստանալ առաջադրանքն ըստ ID-ի     |
| `ListTasks`    | Ստանալ բոլոր առաջադրանքները     |
| `CompleteTask` | Նշել առաջադրանքը որպես ավարտված |
| `DeleteTask`   | Ջնջել առաջադրանքը               |

Սկզբում օգտագործիր `map[string]*Task`՝ որպես պահոց։

### Լրացուցիչ պայմաններ

- Չկրկնվող ID-ներ։
- Չգտնված առաջադրանքի համար՝ `NotFound`։
- Սխալ մուտքային տվյալների համար՝ `InvalidArgument`։
- Գործողությունների համար նախատեսիր `context.Context`։
- Թույլ տուր հաճախորդին սահմանել timeout՝ հարցման կատարման համար։
- Գրիր unit թեստեր և առանձին թեստեր gRPC մեթոդների համար։

### Ի՞նչ պետք է սովորես

- gRPC-ի ստանդարտ սխալների կոդերը։
- Հարցումների վավերացումը։
- Timeout և cancellation մեխանիզմները։
- Ծառայության բիզնես տրամաբանությունը հաղորդակցման շերտից տարանջատելը։
- Ինչպես է ճիշտ կազմակերպվում Go-ի թեստավորումը։
